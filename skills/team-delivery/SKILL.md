# Team delivery v1 (distributable source, not installed authority)

Use Hermes native cards, Dispatcher and existing routine. This skill grants no tools,
credentials, host access, production rights, budgets or resource creation authority.
Never replace a rejected command with a different executor or change runtime policy.

## Onboard before work
1. Record requirement revision, exact native Task/Run, owner, allowed write roots,
   source repository/base/branch, repository completion contract, dependency heads,
   non-goals, test commands, actual runtime/platform/zero-fee limits and separately authorized live budgets and stop rules.
2. Confirm receiving Worker native show/heartbeat. Profile/worktree is not isolation.
   Qualify public networking, private read, author push, PR and independent review
   separately; another actor's successful login proves none of these for a Worker.
3. Use the versioned config schema and immutable shared release. The current trusted
   mapping authorizes only sevenbot-flow-probe; a second repo requires a named grant,
   reviewed mapping and resource delta BEFORE creation. Do not clone YAML per project.
4. Qualify runner/environment/protection/cost/identity/ARM64/image/isolation separately.
   Leave activation unbound when any evidence is absent. Never weaken required checks.

## Actors and sequence
- Orchestrator: settle interfaces, named resource authority, budgets and dependency
  versions; native cards only. No alternate launcher, harness or Actions card updater.
- Developer: app code/tests in its own authorized branch; no deployment identity.
- DevOps: workflows, Docker, bounded operation helpers and reviewed bootstrap; source
  changes need independent review, operations use only fixed reviewed workflows.
- Reviewer: inspect full requirement v2 and retained v1, immutable exact head/diff,
  all test bytes and full logs; independently rerun mandatory suite. Distinct actor,
  exact-head qualified approval. CI success is not review; review is not deployment.
- QA/Architect/Security: contribute only assigned native checks, not invented role
  cards for appearance. Manager owns cross-card publication when code cannot be DONE
  until remote repository gates pass; do not create a circular DONE prerequisite.

## Delivery and rework
Develop → exact-head independent review → required CI → immutable publication →
protected Actions deployment → actual image/version/function health → known-healthy
rollback → newly collected status/API readback → native acceptance. Every arrow is a
separate gate. Public PR code runs only on eligible hosted runners, never Oracle.
Shared workflows retrieve fixed immutable helper commits, not caller-owned scripts.
Use same protected environment concurrency lock for deploy and rollback; never cancel
an active deployment. A stale request must not overwrite a newer source/version.

Return ordinary review findings with native request_changes. Continue evidence-based
repairs within actual runtime/platform/external limits; never delete tests. No default
artificial total-author-run or repair quota applies. Use request_review on the
same card when explicitly specified; never duplicate a review child. Keep repository
contract open until required exact-head remote checks/merge/native acceptance exist.

## Evidence and failure/stop
Handoff includes requirement/config/shared/source SHA, Task/Run, files and hash
manifest, actual commands/stdout/stderr/exits, exact commit/tree/parent/clean-status,
review verdict, PR/head/check runs, artifact SHA/image identity/provenance/run/attempt,
target and actual endpoint/function health, recovery and fresh UTC status age. Mark
missing stages NOT_RUN. Local mocked Docker calls are not host or image proof.

First actual policy/resource refusal: preserve literal payload/result and stop,
without rewrite, alternate actor/tool, privilege or approval changes. A usage error
is not a policy denial. Missing external decisions/auth/infra are native blocked;
normal review is not. Do independent authorized work while another lane is held.
Health failure consumes bounded recovery; rollback failure stops and requires a
native Incident by the authorized manager, never an automatic retry or false PASS.
Never emit tokens, raw Env/inspect, secret-bearing URLs or private logs.

Stop after the assigned handoff. Future work needs a lawful native stage. See
[operations](references/operations.md), [onboarding](../../docs/onboarding.md), and
[acceptance](../../docs/acceptance.md). These references are repository-relative;
installation must preserve them or explicitly adapt their versioned locations.
