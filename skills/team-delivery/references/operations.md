# Native operation and evidence rules

Read native show and upstream exact commits first; heartbeat long operations. Plain
terminal routing variables may be absent; do not fake task/run identity or mutate
labels. Native tools are the ownership surface. Read exact target after an external
write before asserting success. Code edits need reviewed PR; a protected operation
executes fixed reviewed code with bounded arguments, never ad-hoc production shell.

A source card cannot be DONE solely from local tests under a repository contract.
Owner request_review on same card; independent Reviewer returns request_changes or
accepted phase evidence. Manager arranges publication without waiting for source DONE
and performs native acceptance only after the actual required repository gates.

Before retry inspect original refusal/history, claims, current remote main/head/run
and budgets; never replay completed external effects. First policy/resource denial
stops the assigned run. CLI usage mistakes remain distinct. Preserve raw evidence,
no identity/approval/config rewrites or executor substitution. Distinguish local fixture
results from hosted upload/protection/ARM64/health/rollback proof. Absent evidence is
NOT_RUN or UNKNOWN, not PASS. No secret values or raw target inspection in handoff.
